# Distance Between Two Points Calculator - This is the title of the program.

## Description - This introduces the program itself and its overall/main purpose and explains how the distance formula works.

*This program calculates the distance between two points (x1, y1) and (x2, y2) on a 2D plane
using input values (x or y) and a math library (math.sqrt & pow)*

## How to Run - These are the instructions given to the user so that they can run the program and for the program to run smoothly.

1. Open the program file in VS Code, Replit, Google Colab or even a local code interpreter like Programiz.
2. Run the program.
3. Enter the values for x1, y1, x2, and y2.
4. Check the distance displayed on the screen.

## Input/s Needed - These are the required data the user needs to input for the code to work.

- x1
- y1
- x2
- y2

## Sample Output - This is basically what would happenn if a user inputs certain variables like for distance calculation which will then go through a process and display a certain result to the user which is 7.07 in this scenario.

- Enter x1: 2
- Enter y1: 3
- Enter x2: 7
- Enter y2: 8

The distance between the two points is: 7.07
